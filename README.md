
# 🍳 Receitário — Checkpoint 5

## 📖 Sobre o projeto

O **Receitário** é um site desenvolvido para o Checkpoint 5 da disciplina de Frontend da FIAP, com o objetivo de criar um catálogo de receitas utilizando React, Vite e TypeScript.

A aplicação utiliza a API DummyJSON para buscar e apresentar diferentes receitas, permitindo que o usuário encontre opções de forma rápida e organizada.

O projeto conta com uma interface simples e intuitiva, oferecendo funcionalidades de pesquisa, filtros por tipo de culinária e a possibilidade de marcar receitas como favoritas.

## ⚙️ Funcionalidades

- 🍽️ **Catálogo de receitas:** listagem com imagens, nomes e tempo de preparo.
- 🔎 **Pesquisa:** busca de receitas pelo nome.
- 🌎 **Filtros:** seleção de receitas por tipo de culinária.
- ❤️ **Favoritos:** opção de favoritar receitas com contador.
- 📖 **Detalhes:** visualização dos ingredientes, modo de preparo e tempos.
- 📱 **Layout responsivo:** adaptação para diferentes tamanhos de tela.
- ⚠️ **Tratamento de erros:** páginas para receitas inexistentes e endereços inválidos.

## 💻 Tecnologias utilizadas

- React
- Vite
- TypeScript
- React Router
- CSS
- DummyJSON API
