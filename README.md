
# Receitário

Projeto desenvolvido para o Checkpoint 5 de Frontend da FIAP.

## Integrantes

- Nome completo - RM

## Tecnologias utilizadas

- React
- Vite
- TypeScript
- React Router
- DummyJSON API

## Funcionalidades

- Listagem de receitas
- Pesquisa pelo nome
- Filtro por culinária
- Favoritos
- Página de detalhes
- Tratamento de erros
- Página 404

## Como executar

Instalar as dependências:

npm install

Iniciar o projeto:

npm run dev

Verificar a compilação:

npm run build

## Deploy
